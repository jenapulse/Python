# Employee HR Data Analysis Using Python

## 📌 Project Overview
This project focuses on analyzing HR employee data using Python to understand workforce demographics, departmental distribution, and salary patterns. The project demonstrates data cleaning, transformation, exploratory data analysis (EDA), and data visualization.

## 🎯 Objectives
- Clean and preprocess employee data.
- Analyze employee distribution by department, age, gender, and marital status.
- Compare salary patterns across departments and gender groups.
- Visualize workforce trends using charts and statistical plots.

## 🛠️ Tools & Technologies
- **Python**
- **Pandas** – Data manipulation and analysis
- **NumPy** – Numerical operations
- **Matplotlib** – Data visualization
- **Seaborn** – Statistical visualization
- **Jupyter Notebook** – Interactive analysis

## 📂 Project Structure
```text
Employee-Data-Analysis-Python/
├── Sample_HR.csv

└── README.md
```

## 🔍 Project Workflow
1. **Data Loading:** Imported HR data from a CSV file.
2. **Data Cleaning:** Checked and handled duplicate records and missing values.
3. **Data Transformation:** Standardized selected fields and created derived columns.
4. **Exploratory Data Analysis:** Examined workforce demographics and departmental distribution.
5. **Data Visualization:** Created bar charts, line charts, pie charts, histograms, and box plots.
6. **Insights:** Used visualizations to explore workforce composition and salary differences.

## 📊 Key Analysis Areas
- Employee count by department
- Age and gender distribution
- Employee distribution by marital status
- Average salary comparison by department and gender
- Age distribution
- Salary distribution across departments and gender groups

## ▶️ How to Run the Project
1. Clone or download this repository.
2. Install the required libraries:
   ```bash
   pip install pandas numpy matplotlib seaborn jupyter
   ```
3. Open the project folder in a terminal.
4. Launch Jupyter Notebook:
   ```bash
   jupyter notebook
   ```
5. Open `Employee_HR_Data_Analysis.ipynb` and run the cells sequentially.

## 💡 Conclusion
This project demonstrates how Python can be used to clean, analyze, and visualize HR data. The analysis provides a foundation for understanding workforce demographics, departmental distribution, and compensation patterns to support data-driven HR decision-making.
